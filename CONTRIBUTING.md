# Contributing to Tracelify SDK

Thanks for your interest in contributing! 🎉

## How to contribute
1. Fork the repo and create a feature branch (`git checkout -b feat/my-change`).
2. Follow the existing code style (run `flake8` / formatter before pushing).
3. Add or update tests for your change.
4. Open a Pull Request with a clear description of the change and motivation.

## Development setup
```bash
pip install -e ".[dev]"
# or for other languages, see the per-language package in src/
```

## Reporting bugs
Open an issue using the bug template and include reproduction steps + SDK version.

## Code of Conduct
Be respectful. We follow the standard open-source contributor covenant.
